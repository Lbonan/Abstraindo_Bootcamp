# Abstraindo Bootcamp

Exercício desenvolvido durante um bootcamp da **DIO (Digital Innovation One)** com o objetivo de praticar conceitos fundamentais da **Programação Orientada a Objetos (POO)** em Java.

## 🎯 Objetivo

O projeto foi desenvolvido para colocar em prática principalmente os conceitos de:

* **Herança**
* **Polimorfismo**
* **Abstração**
* **Encapsulamento**

A proposta é trabalhar com classes e objetos, utilizando uma estrutura simples para entender como esses conceitos podem ser aplicados no desenvolvimento em Java.

## 🛠️ Tecnologias

* Java
* Maven

## 📚 Conceitos praticados

### Herança

Utilização de classes que herdam características e comportamentos de outras classes, permitindo o reaproveitamento de código.

### Polimorfismo

Permite que objetos de diferentes classes sejam tratados de forma semelhante, enquanto cada classe pode apresentar seu próprio comportamento.

### Abstração

Representação das características essenciais dos objetos, mantendo o foco no que é importante para o funcionamento do sistema.

### Encapsulamento

Organização e proteção dos dados e comportamentos dentro das classes.

## 🚀 Sobre o projeto

Este foi um exercício prático realizado durante um bootcamp da **DIO**, com foco no aprendizado dos fundamentos da Programação Orientada a Objetos utilizando Java.

O projeto tem como principal objetivo reforçar os conceitos de **herança e polimorfismo** através de uma implementação simples e prática.
